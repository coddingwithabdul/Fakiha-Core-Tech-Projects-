# Skill Swap

Skill Swap is a static website concept for a campus community where students can discover one another's skills, share what they know, and find learning partners.

## Features

- Landing page with links to the main sections
- Overview of how a peer-to-peer skill exchange could work
- Example student profiles showing skills offered and wanted
- Skill category cards and an introduction to the concept
- Contact form with the browser's built-in required-field validation
- Responsive page layouts for narrower screen sizes

The student profiles and headline counts are illustrative content in the page, not live community data. The contact form is front-end only and is not connected to a service that receives messages.

## Technologies

- HTML5
- CSS3
- Google Fonts (Poppins)
- Font Awesome, loaded from its CDN

There is no JavaScript, server, or package manager required. The hero photo is loaded from Unsplash; the font and icon styles also require an internet connection.

## Run locally

1. Clone or download this repository.
2. Open `Skill Swap/index.html` in a browser.

For live reload while editing, open the `Skill Swap` folder in Visual Studio Code and use the Live Server extension. The included workspace setting selects port `5502`.
